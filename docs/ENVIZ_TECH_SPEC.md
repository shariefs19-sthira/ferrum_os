## License flags — commercial use

**None of the seven blocks above carry a license that blocks commercial use outright.** The one nuance requiring care, not avoidance: **Speckle server's `workspaces/` and `gatekeeper/` module directories are proprietary EE-licensed** — safe to ignore entirely by only running/depending on the Apache-2.0-licensed remainder of that codebase, which is exactly what the "concept-only, not now" recommendation above already does.
