# LandIntel 2D/3D site map — live render evidence (MASON, 2026-09-19)

Generated by `node scripts/site3d-evidence.mjs` against the static export (`apps/web/out`), headless Chromium (SwiftShader WebGL2), live OpenFreeMap vector tiles. Viewports 320/390/768/1024/1440.
Measured data: `results.json` (per viewport: 2D, 3D, after rotate/tilt/recenter, back to 2D).

## Data availability actually observed
- Covered — MG Road, Bengaluru (12.97567, 77.60733): OSM footprints render as extrusions. Footprints in view: 30 (320), 35 (390), 63 (768), 75 (1024), 112 (1440); 10/12/18/21/29 of them at the assumed 5 m default height, the rest OSM-derived height.
- No-building — open sea, Bay of Bengal (12.5, 82.5): 0 footprints, honest "No OpenStreetMap building footprints found" state, nothing drawn.
- Unavailable — OpenFreeMap requests aborted: 3D falls back to the Leaflet 2D plan with a visible message (`unavailable-tiles-blocked-*`). WebGL2 absent: 3D toggle disabled with a visible reason (`unavailable-no-webgl2-*`).

## Checks recorded in results.json
- Marker tip vs map centre offset 0/0 px in 3D at every viewport, before and after rotate + tilt + recenter; camera centre equals the entered coordinates.
- Selected-point text equals entered coordinates in 2D, 3D and back in 2D.
- Map centre not covered by any card/control (`centreObscuredByUi=false`); record card is in-flow below the map under 1200 px and an overlay only at ≥1200 px, not over the centre.
- Smallest button 44×44 px; no horizontal overflow.
- Toggle buttons sit above the map, so with the map scroll-centred the sticky site header covers them (flag `coveredByStickyHeaderUntilScrolled`); they are reachable once scrolled into view.
- Console noise: `HTTP 404 /api/region` is the static server lacking the Worker API (unrelated component).

## CSP finding (needs CRANE; `_headers` not edited here)
`-csp-current/`: with the deployed CSP from `apps/web/public/_headers`, 3D cannot load (`connect-src` lacks `https://tiles.openfreemap.org`); every run falls back to 2D with the visible message. `-csp-proposed/`: adding `https://tiles.openfreemap.org` to `connect-src` and `blob:` to `img-src` renders 3D at all viewports.
