# SUTRA orchestration responsive evidence

This folder records local development rendering evidence for the integrated SUTRA workflow panel. It is **NOT LIVE**: it neither proves a deployment nor external-provider access. The panel records the fail-closed external-sensitive-access boundary and no source citations are fabricated for its initial `UNKNOWN` state.

Run `FERRUM_AUDIT_BASE_URL=http://127.0.0.1:3017 node scripts/mason-sutra-orchestration-responsive-audit.mjs` while the local web app is running. The report verifies the required viewports, one SUTRA surface, one Extract control, visible workflow panel, HTTP status, browser errors, and horizontal overflow.
