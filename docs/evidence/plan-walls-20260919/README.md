## Limitations (honest status)

- Only the four interior partitions of the deterministic layout are movable (all floors together).
  Exterior walls are selectable and measured but read-only; no wall add/delete/split, no per-floor moves.
- Thickness (230 mm exterior / 115 mm interior) and height (= storey height) are assumed defaults, not
  surveyed or structurally designed. Nothing here is load-path, structural design or code-compliance output.
- The 3D wall model is a toggle in the 3D status bar (default off, so the landed massing view and
  walkthrough are unchanged); the roof is hidden while it is on. At the default axonometric camera the plan
  is a small part of the frame, so a partition move changes about 0.4–0.65 % of canvas pixels.
- "Recorded outputs" (BOQ + structural) is a cockpit-local record of the geometry revision they were
  computed against. `apps/web/app/boq-pro/**` is protected and still rebuilds its plan from parameters only, so
  it does not yet read opening or wall edits — that needs a CRANE-owned follow-up.
- Downstream outputs are INDICATIVE. The IS 456 span check shown is the existing simplified check.
