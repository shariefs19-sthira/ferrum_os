# Ferrum OS / Ferrum Projects — Implementation Status Matrix (2026)

Tracks every accepted requirement from this work stream against real,
checkable state: what branch/commit it lives on, what was actually run
to validate it, and what's still open. Written directly against git
and this session's own verification runs, not against a claimed
status — a row is never marked beyond what the evidence in its own
"Validation evidence" column actually shows.

**Status legend** (all requirements in this doc are currently at most
`PUSHED` — nothing from this work stream has been merged to
`origin/main`, deployed, or verified on a live deployed edge):

- `NOT_STARTED` — no implementation exists.
- `PARTIAL` — some but not all of the requirement is implemented.
- `PUSHED` — implemented, committed, pushed to a remote branch; not
  merged to `origin/main`.
- `LANDED` — merged to `origin/main` via `scripts/land.ps1`.
- `DEPLOYED` — the landed SHA has been pushed live via `wrangler deploy`.
- `LIVE_VERIFIED` — someone has loaded the actual deployed URL (or
  curled it) and confirmed the change is really there.
